## 🚀 使用与配置说明

### 1. 手动一键触发每日早报更新
1. 进入本仓库的 **[Actions 页面](https://github.com/airt56/auto-green/actions)**。
2. 在左侧工作流列表中点击 **🟩 Daily Auto-Green & Tech Digest**。
3. 点击右侧的 **Run workflow** 按钮 -> 保持默认参数 `0`（代表随机提交 1~5 次）-> 点击绿色的 **Run workflow**。
4. 等待约 15 秒运行完成，刷新仓库首页即可看到最新抓取的 **GitHub 热榜** 与 **Hacker News 资讯**！

### 2. 自动运行时间
- 工作流默认在每天 **北京时间 09:25**（UTC `01:25`）自动执行。
- 如需修改运行时间或频次，可编辑 [`.github/workflows/daily-green.yml`](.github/workflows/daily-green.yml) 中的 `cron` 表达式。

### 3. 本地命令参考
```bash
# 查看 7x35 HELLOW 像素画布预览
python scripts/draw_pixel_art.py

# 拉取今日资讯并更新 README 与归档文件（不执行 git commit）
python scripts/auto_green.py

# 自动生成 1~5 次随机 Git 提交
python scripts/auto_green.py --auto-commit
```
