## ✨ 项目特性

1. **☁️ 纯云端零成本运行**：基于 GitHub Actions `schedule` 定时任务，无需购买服务器，无需本地电脑开机。
2. **🎨 绿格子深浅自然变化**：每天在 `1 ~ 5` 次之间随机决定提交次数，分阶段提交打卡数据、极客格言、GitHub 热榜、Hacker News 资讯与看板更新，让你的 GitHub 贡献图呈现自然的深浅绿阶梯。
3. **📚 真正有价值的仓库内容**：拒绝无意义的乱码刷屏，每天自动归档一份精美的《每日技术早报》至 [`archives/`](archives/) 目录。
4. **🔐 自动绑定本人账号绿格子**：内置自动识别仓库所有者的 GitHub 官方 `noreply` 邮箱（`<id>+<username>@users.noreply.github.com`），无需繁琐配置即可 **100% 计入你个人主页的绿格子**。
5. **⚡ 零第三方依赖**：纯 Python 3 标准库实现，运行仅需数秒，永不因第三方包版本冲突而失败。

## 🚀 3 步快速启用指南

### 第一步：上传本项目到你的 GitHub 仓库
1. 在 GitHub 上新建一个仓库（建议设为 **Public 公开仓库**；若设为 Private 私有仓库，请开启个人主页的 `Private contributions` 显示开关）。
2. 将本项目代码推送到该仓库的默认分支（`main` 或 `master`）：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for GitHub Auto-Green"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<你的仓库名>.git
   git push -u origin main
   ```

### 第二步：手动一键测试（验证绿格子）
1. 进入你刚创建的 GitHub 仓库页面，点击顶部的 **Actions** 标签页。
2. 在左侧工作流列表中点击 **🟩 Daily Auto-Green & Tech Digest**。
3. 点击右侧的 **Run workflow** 按钮 -> 保持默认参数 `0`（代表随机提交 1~5 次）-> 点击绿色的 **Run workflow**。
4. 等待约 10~15 秒运行完成，刷新仓库首页即可看到自动更新的科技早报看板，再去你的 GitHub 个人主页即可看到今天的绿格子已经点亮！

### 第三步：享受全自动每日点绿
- 工作流默认在每天 **北京时间 09:25**（UTC `01:25`）自动执行。
- 如果你想修改运行时间或每天运行的频次，只需编辑 [`.github/workflows/daily-green.yml`](.github/workflows/daily-green.yml) 中的 `cron` 表达式即可。

## 🛠️ 常见问题与进阶配置

### 1. 为什么运行成功了，但个人主页没有变绿？
GitHub 统计贡献绿格子有以下规则，本项目已默认帮你处理好，但请确认：
- **分支要求**：代码必须提交在仓库的 **默认分支**（通常是 `main` 或 `master`），且仓库**不能是 Fork 别人的仓库**。
- **邮箱匹配**：本项目默认使用 `${{ github.repository_owner_id }}+${{ github.repository_owner }}@users.noreply.github.com`，这是 GitHub 官方为你账号绑定的专属隐私邮箱，默认必然计入绿格子。如果你想指定自己的常用邮箱，可以在仓库 `Settings` -> `Secrets and variables` -> `Actions` -> `Variables` 中新增变量 `GIT_USER_EMAIL`。
- **私有仓库显示**：如果你创建的是私有仓库（Private），需要在你 GitHub 个人主页贡献图右上角的 `Contribution settings` 中勾选 **Private contributions**。

### 2. 本地如何手动运行预览？
```bash
# 仅拉取今日资讯并更新 README 与归档文件（不执行 git commit）
python scripts/auto_green.py

# 本地测试自动生成 3 次 Git 提交
python scripts/auto_green.py --auto-commit --commits 3
```
